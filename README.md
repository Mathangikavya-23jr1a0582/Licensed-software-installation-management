# Licensed Software Installation Management

## Project Overview
This project automates the licensed software installation request process using ServiceNow. It streamlines request submission, approval workflows, software deployment, and user notifications.

## Features
- Software request through Service Catalog
- Manager approval workflow
- Automated task creation
- Software installation tracking
- Email notifications
- Request status monitoring

## Technologies Used
- ServiceNow
- Flow Designer
- Service Catalog
- Workflow Automation
- GitHub

## Project Documents
- Solution Architecture
- Proposed Solution
- Data Flow Diagram
- Problem Solution Fit
- Brainstorming Document

## Workflow
1. User submits software installation request.
2. Manager approves or rejects the request.
3. IT team receives the installation task.
4. Software is installed.
5. User receives confirmation.
